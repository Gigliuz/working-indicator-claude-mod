# working-indicator

A Claude Code mod that shows a small animated row above the chat prompt whenever Claude is actively working — a spinner, elapsed time, and a running crab (🦀) — so the chat never looks frozen while a turn, or a background subagent, is in progress. The row disappears automatically once the work is done.

## Install

At the prompt of a terminal session:

```
/plugin install working-indicator --marketplace Gigliuz/working-indicator-claude-mod
```

Or from a shell:

```
claude plugin install working-indicator --marketplace Gigliuz/working-indicator-claude-mod
```

In the desktop app, where `/plugin` does not run: click **+** next to the prompt box, then **Plugins**, **Add marketplace** with `Gigliuz/working-indicator-claude-mod`, then **Add plugin**.
